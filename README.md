# 아이온2 파티 메이커

본캐와 부캐 명단을 등록해 두고 **무스펠 · 비탄** 던전별로 그룹과 파티를 빠르게 편성해 이미지(PNG)나 공유 링크로 나눌 수 있는 브라우저 웹 앱입니다.

- **라이브 주소**: https://partymaker-rho.vercel.app/

## 실행 및 배포

- **로컬 실행**: `index.html`(또는 `아이온2 파티메이커.html`)을 브라우저에서 열면 별도 설치나 서버 없이 바로 사용할 수 있습니다.
- **Vercel 배포**: GitHub 저장소를 Vercel에 연결하면 추가 빌드 설정 없이 루트(`index.html`) 기준으로 자동 배포됩니다. (`vercel.json` 포함)

---

## 주요 기능 및 동작 방식

### 1. 캐릭터 등록 및 명단 관리
- **계정별 본캐 · 부캐 등록**: 계정마다 본캐 1명과 부캐 여러 명(닉네임 · 직업 · 전투력)을 등록합니다. 캐릭터 수가 가장 많은 계정에 맞춰 1그룹, 2그룹, 3그룹…이 자동으로 생성됩니다.
- **9개 직업 아이콘 & 고유 색상 테마**: `검성 · 수호성 · 궁성 · 살성 · 마도성 · 정령성 · 치유성 · 호법성 · 권성` 각 직업의 엠블럼 아이콘과 대표 색상이 등록 드롭다운, 명단, 파티 슬롯, 필터, PNG 편성표 전체에 통일 적용됩니다.
- **명단 내 인라인 부캐 추가 · 수정 · 삭제**: 이미 등록한 계정 카드의 `＋ 부캐 추가` 버튼으로 계정을 지우지 않고 바로 부캐를 추가할 수 있으며, 각 캐릭터의 `✎` 버튼으로 닉네임 · 직업 · 전투력 수정 및 부캐 개별 삭제가 가능합니다.
- **직업 · 역할 필터**: `전체 / 탱커 / 딜러 / 힐러` 빠른 필터와 9개 직업별 아이콘 필터(다중 선택 지원)를 제공하며, 각 직업 버튼에 현재 등록된 인원 수가 실시간으로 표시됩니다.
- **그룹별 투입 가능 인원 필터**: 그룹 카드의 `투입 가능` 버튼(또는 그룹 제목, 명단 상단 그룹 버튼)을 누르면, 이미 배치된 캐릭터와 해당 그룹에 본캐·부캐 중 한 명이라도 들어가 있는 계정 전체를 숨기고 **실제로 투입 가능한 남은 인원만 강조 표시**합니다. 선택과 동시에 `빠른 배치 위치`도 해당 그룹으로 자동 연동됩니다.
- **명단 패널 스크롤 추적(Sticky)**: 그룹이 많아져 페이지를 아래로 스크롤할 때도 왼쪽 캐릭터 명단이 화면 상단에 고정되어 함께 따라오므로, 2·3그룹 아래에서도 바로 명단을 확인하며 배치할 수 있습니다.

### 2. 던전별 관리 및 수동 · 드래그 편성
- **무스펠 · 비탄 독립 관리**: 상단 탭으로 던전을 전환하며, 각 던전의 파티 편성 · 그룹 설정 · 최소 전투력 기준(K)은 서로 독립적으로 저장됩니다. (전투력 기준을 비워 두면 제한 없이 편성)
- **계정당 1캐릭터 제한**: 한 그룹(1·2파티 합산) 안에서는 같은 계정의 캐릭터(본캐·부캐 통틀어)가 1명만 배치되도록 자동으로 검증합니다.
- **드래그 중 휠 스크롤 지원**: 커스텀 포인터 드래그를 적용해, 캐릭터를 클릭해 손에 쥔 상태에서도 **마우스 휠을 굴리거나 화면 위·아래 가장자리로 커서를 가져가면 페이지가 스크롤**되어 아래 그룹(2·3그룹 등) 슬롯에 바로 끌어 놓을 수 있습니다.
- **빠른 배치 & 슬롯 고정(자물쇠)**: `＋` 버튼으로 지정한 그룹·파티의 빈 자리에 즉시 배치할 수 있으며, 수동으로 배치한 캐릭터는 자동으로 **고정** 상태가 되어 자동 편성 시 유지됩니다. 슬롯 우측 자물쇠 버튼으로 언제든 고정/해제를 전환할 수 있습니다.

### 3. 유동 자동 편성 엔진 및 그룹 설정
- **전체 / 개별 그룹 자동 편성**: 수동 고정된 슬롯은 그대로 유지한 채, 체크된 후보 중 전투력 기준을 충족하는 캐릭터로 남은 빈 자리를 자동 편성합니다.
- **2힐 정석 시너지 우선 (`치유성 + 호법성`)**: 힐러가 2명인 파티를 구성할 때 `치유성`이 배치되면 `호법성`을, `호법성`이 배치되면 `치유성`을 우선 매칭해 정석 5인 조합(`탱1 · 딜2 · 치유1 · 호법1`)을 완성합니다.
- **1·2파티 라운드 로빈 균형 배분**: 한 파티가 탱커·힐러를 독점하지 않도록 1파티와 2파티에 먼저 `탱1 · 힐1`씩 골고루 배분한 뒤 2번째 힐러와 딜러를 채웁니다.
- **역할 부족 시 유동 조합 자동 대체**: 설정한 정석 역할을 우선 채우고, 인원이 부족해 빈 자리가 생기면 아래 순서로 자동 대체해 빈 슬롯을 최소화합니다.
  - 힐러 부족 → `딜러` → `탱커` (`탱1 · 딜3 · 치유1` / `탱1 · 딜3 · 호법1`)
  - 탱커 부족 → `딜러` → `호법성/치유성` (`딜4 · 호법1` / `딜4 · 치유1`)
  - 딜러 부족 → `탱커(검성/수호성)` → `호법성/치유성`
- **자동 슬롯 정렬**: 자동 편성된 슬롯(고정 슬롯 제외)은 `탱커 → 딜러 → 치유성 → 호법성`(동일 역할 내 전투력 순)으로 자동 정렬됩니다.
- **그룹별 세부 설정 & 빠른 프리셋**: 그룹 편성 설정 창에서 `본캐 목표 수(0~10)`, `부캐 자동 충원`, `유동 조합 허용` 여부를 개별 설정할 수 있으며, `정석(1·2·2)` / `1힐(1·3·1)` / `노탱(0·4·1)` 원클릭 프리셋을 지원합니다.

### 4. 저장 · 기기 동기화 · 공유 및 가이드
- **브라우저 자동 저장**: 등록한 명단과 던전별 편성, 그룹 설정이 `localStorage`에 즉시 자동 저장됩니다.
- **코드 저장 · 불러오기 & 공유 링크**: 전체 데이터를 압축 저장 코드(`AION2...`)나 공유 링크(`#data=...`)로 복사해 다른 기기·브라우저에서 복원할 수 있습니다. (`전체 불러오기` / `명단만 불러오기` 지원)
- **파티 편성표 PNG 공유**: 전체 그룹 또는 특정 그룹만 선택해 직업 아이콘과 고유 색상이 포함된 고해상도(2x) 요약 편성표 이미지를 미리보고, PNG 파일 저장 또는 클립보드 복사(`Ctrl+V`)로 카카오톡·디스코드에 바로 공유할 수 있습니다.
- **4단계 팝업 튜토리얼 가이드**: 처음 방문 시 핵심 사용법 팝업이 자동으로 열리며, 상단 `? 사용법` 버튼으로 언제든 다시 확인할 수 있습니다.
