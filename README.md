# 아이온2 파티 메이커

본캐와 부캐를 등록하고 무스펠·비탄 던전별로 그룹과 파티를 관리하는 브라우저 앱입니다.

## 실행

`아이온2 파티메이커.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 설치할 패키지나 서버가 필요하지 않습니다.

## 기능

- 계정별 본캐와 여러 부캐 등록
- 직업, 전투력 기준 캐릭터 명단 관리
- 무스펠과 비탄 섹션을 탭으로 전환하고 별도로 저장
- 캐릭터 수가 가장 많은 계정을 기준으로 그룹 자동 생성
- 그룹마다 1파티와 2파티 편성
- 한 그룹 안에서 계정당 한 캐릭터만 허용
- 그룹 설정에서 파티별 탱커·딜러·힐러 수 지정
- 그룹별 본캐 목표 수와 남은 역할 자리를 부캐로 채우는 옵션
- 던전별 전투력 기준(K) 설정. 비워 두면 기준을 적용하지 않음
- 현재 파티원에게 본캐·부캐 유형 표시
- 그룹별 또는 전체 자동 편성 (수동 배치해 고정한 캐릭터는 유지하고 빈 자리만 자동 편성)
- 캐릭터를 끌어 놓거나 빠른 배치 버튼을 눌러 수동 편성 및 슬롯별 고정/해제
- 브라우저 저장소에 명단과 편성 자동 저장

그룹 수는 계정별 캐릭터 수 중 최댓값에 맞춰 자동으로 늘어납니다. 각 그룹은 1파티와 2파티로 구성되며, 파티당 최대 5명을 배치할 수 있습니다. 역할 수는 그룹 설정 창에서 바꿀 수 있고 기본값은 파티당 탱커 1명·딜러 2명·힐러 2명입니다. 전투력 입력 단위는 천 단위(K)이며, 예를 들어 45K는 캐릭터 전투력 45,000 이상을 뜻합니다. 전투력 기준은 자동 편성에 적용되며, 비워 두면 제한이 없습니다.
